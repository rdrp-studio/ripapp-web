# RIPAPP · web

Web de presentación de RIPAPP (RDRP Studio), en 6 idiomas.

- `index.html`: la página.
- `privacidad.html`: la política de privacidad en los 6 idiomas.
- `i18n.js`: los textos en español, inglés, alemán, francés, italiano y portugués.
- `img/`: icono, foto y capturas (`img/<idioma>/`).

GitHub Pages: rama `main`, carpeta `/ (root)`.
